# Contributing to redox-rpi

This is the default contributing guide for every repository of the
[redox-rpi](https://github.com/redox-rpi) organisation that has none of its
own. The same rules apply everywhere, for people and AI agents:

- The full guide: [CONTRIBUTING.md in redox-rpi/redox-rpi](https://github.com/redox-rpi/redox-rpi/blob/main/CONTRIBUTING.md)
- Roles, merge rights and the rules for all repositories: the
  [project management plan](https://github.com/redox-rpi/redox-rpi/blob/main/docs/process/pmp.md#all-repositories)

In short: say in the issue that you take it, code goes through a branch and
a pull request that names the issue, docs go straight to the default
branch, and only those with the merge right merge.
